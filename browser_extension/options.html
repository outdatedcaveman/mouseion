📚 zoterpile

Browser extension settings — connect to your zoterpile server

Server Connection

The URL where your zoterpile server is running.
Use http://localhost:7274 for a local server, or your public URL if hosted remotely.

The API key is printed in the terminal when you start zoterpile with zoterpile web.
You can also find it in the ⚙ Settings modal in the web UI.

Usage Tips

• Click the extension icon to save a reference from the current page.
• Right-click any link or selected text and choose Save to zoterpile.
• DOI, arXiv IDs, and citation metadata are detected automatically.
• Use zoterpile web --public to allow access from other devices.
